Loja de Instrumentos Musicais

Projeto em Java que simula o cadastro de uma loja de instrumentos musicais. O sistema trabalha com duas categorias, harmonia e percussão, e armazena os dados em um banco de dados relacional.

Funcionalidades:

- Conexão com o banco de dados
- Cadastro de instrumentos de harmonia e de percussão
- Orientação a objetos com classes para cada tipo de instrumento

Tecnologias: Java, JDBC, MySQL Workbench
